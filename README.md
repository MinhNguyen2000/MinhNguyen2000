🦾 **Current Robotic and Control Projects**
- Experiments with DRL algorithms in gymnasium environments ([experiment repo](https://github.com/MinhNguyen2000/experiment/tree/main/DRL))
  - [x] **FrozenLake-v1** (discrete state & action) for testing classic RL methods such as Monte Carlo (MC), Temporal Difference (1-step TD with n-step TD coming), and REINFORCE.
  - [x] **CartPole-v1** (continuous state & discrete action) for testing DQN, Double DQN, REINFORCE, A2C, and PPO.

  - [x] **MuJoCo InvertedDoublePendulum-v5** (continuous state & action) for testing the portability and performance of the TD3 algorithm created in Inverted Pendulum
